安装包约 309 MB，包含离线 Word 转 PDF 组件。安装包尚未数字签名，Windows 可能提示“未知发布者”。

## 功能

- PDF 合并、文件拖动排序、合并结果预览。
- 内置 PDF 阅读器，支持缩略图、翻页、缩放和滚轮浏览。
- 复制文字、删除文字或整页、撤销并另存为，保留原文件。
- PDF、DOCX 与图片格式转换；PDF 转 Word 的文字和常规表格可编辑。
- v1.3.1 默认启用窗口拖动兼容处理，缓解拖动滞后及松手后继续移动的问题。

所有文档在本机处理，不上传文件。

## 注意事项

- 普通窗口暂不支持拖到屏幕边缘自动贴靠，可用 **Win + 方向键**。
- 扫描 PDF 暂不支持 OCR；复杂排版转换后可能需要人工调整。
- 文字删除不自动重排，也不作为保密脱敏工具。
